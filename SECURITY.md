# Security Policy

## Supported versions

This project is an early community draft. Security corrections are applied to the default branch. No long-term support or security response SLA is promised.

## Reporting a vulnerability

If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security -> Report a vulnerability** workflow. Otherwise, contact the repository maintainer through an existing private channel listed on their GitHub profile. Do **not** post access tokens, private infrastructure identifiers, proof-of-concept payloads targeting live systems, or exploit instructions in a public issue.

Include the affected file, protocol version, expected security invariant, observed behavior, and a minimal reproduction against a local disposable test environment where practical.

## Scope disclaimer

This repository supplies agent guidance; it is not an authorization enforcement library. Actual security depends on server code, deployed policy, trust boundary configuration, and tests executed against the target implementation.

No security guarantees or audit certification are implied by the MIT License or by CI status.
